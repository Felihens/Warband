WARBAND - HOW TO INSTALL
=======================

Requires BepInEx for Valheim.

MANUAL
1. Extract this zip.
2. Open the "plugins" folder from the zip.
3. Copy the "Warband" folder into:
       Valheim\BepInEx\plugins\

   Result:
       Valheim\BepInEx\plugins\Warband\Warband.dll

4. Launch the game.

R2MODMAN / THUNDERSTORE MOD MANAGER
Settings > Import local mod > pick this .zip (don't extract it).

UPDATING
Delete the old Warband folder first.

Config: press F1 in game (Configuration Manager) or edit
Valheim\BepInEx\config\felih.Warband.cfg. See README.md.
